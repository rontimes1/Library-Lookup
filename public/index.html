Unchecked fields are ignored - join connects to the nearest field above that is turned on, so an unchecked field in between does not matter.

Print labels without the pop-up box

Normally your browser shows a print box every time. To make a label print the instant you scan, set up Chrome once. It takes about two minutes.

  1. Make your label printer the default.
    Open Windows Settings → Bluetooth & devices → Printers & scanners. Turn off "Let Windows manage my default printer," then click your label printer and choose Set as default.
  2. Add one setting to Chrome's shortcut.
    Close Chrome completely. Right-click your Chrome icon → Properties. In the Target box, click at the very end, press the spacebar once, then type: --kiosk-printing and click OK.
  3. Reopen Chrome using that icon and load this page again.
  4. Turn on the "Print" checkbox next to "On each scan." Now every scan prints a label right away, with no pop-up.

This always prints to your default printer, so make sure the right one is set as default. To go back to normal printing, remove --kiosk-printing from the shortcut.
Printing and alignment help

Labels can print a little off because every printer is slightly different. If your text is not landing inside the labels, check these settings in order. The first one fixes most problems.

Applies to all label printing

  1. Print at 100% (Actual size).
    In the browser's print box, set Scale to 100 or Default. Never use Fit to page or Shrink to fit - that shrinks every label and is the most common cause of misalignment.
  2. Keep Margins on "Default".
    If you pick None, Minimum, or Custom, the browser ignores this app's label spacing and calibration.
  3. Do a test print on plain paper.
    On the Sheet labels or Label maker tab in Settings, click Print alignment test to print empty outlines. Hold the page against a blank label sheet up to the light and see whether the boxes line up.
  4. Calibrate if it is still off.
    Use the up / down / left / right pad to nudge the labels 0.01 inch per click until the test lines up. Name a profile per printer (for example "Office printer") and pick it before printing. Default Template always matches the official specs.

3-across sheet labels (Avery 5160)

  • Set paper size to Letter and orientation to Portrait.
  • This sheet follows the Avery 5160 layout: 30 labels, 3 across and 10 down. Avery has printer-specific tips here: fixing shrunk or misaligned prints and recommended printer settings.
  • If every label is shifted the same way, calibrate the sheet profile. If only some rows or columns drift, re-check that Scale is set to 100%.

Label maker / single labels

  • Set the printer's paper or label size to your label stock (for example your Brother label size), not Letter.
  • Each label prints on its own page. Use the alignment test on the Label maker tab to check the fit.
  • If the text sits too high, too low, or to one side, calibrate the label maker profile with the nudge pad.

Some printers cannot print all the way to the edge of the page, so a small shift is normal.
